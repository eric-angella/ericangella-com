---
title: "Why I finally left WordPress behind"
excerpt: "Ten years of managing other people's WordPress sites will teach you exactly what you don't want for your own."
date: 2026-07-01
---

I've spent a decade in other people's WordPress installs — fixing broken plugins, chasing down mystery white screens, explaining for the hundredth time why an update broke a theme nobody remembers customizing.

None of that made me want to run WordPress for myself.

## The actual requirements

What I wanted was simple: write in markdown, push to git, have the site update. No database. No admin panel to secure. No plugin dependency tree to keep alive.

That's it. That's the whole list.

## What replaced it

A static site generator, a git repository, and a host that redeploys on push. Writing a post is now indistinguishable from writing a text file — because it is one.

The tradeoff is real: no drag-and-drop page builder, no plugin marketplace. But I wasn't using those for anything I couldn't do better in code anyway.
